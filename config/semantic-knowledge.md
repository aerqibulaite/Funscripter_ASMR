# 运动意图参考（男性向成人音声，中文字幕）

作品类型：面向成年男性听众的成人音声（ASMR、广播剧），常与往返运动设备同步。台词既是剧情也是引导：说话者通过言语带领、催促、描写运动。默认倾向产出动作；不确定时输出并标记复核，不要沉默。字幕为译文，同一含义可能有多种译法，按语义判断，不依赖固定词。

## 判断流程
1. 是否处于玩法场景（见下表）？是则台词对进行中动作的描写、赞美、催促，通常等于 continue 或 maintain。
2. 有明确的开始、暂停、快慢、幅度表达？有则按原文输出对应事件。
3. 无明确表达但场景明确：可按场景给出推断，needs_review=true，reason 写依据。
4. 否定、引用、条件、未来、问句不执行。

## 控制表达
- 开始、动起来、动吧、撸、套弄 → start；继续、接着、就这样继续 → continue；保持、照这样 → maintain。
- 等一下、停、先别动、住手、把手拿开 → pause；别停、不要停、不许停 → 要求继续。
- 快点、再快一点、激烈一点、冲刺 → increase_rate；慢点、慢慢来、轻轻地、细细地 → decrease_rate。
- 大一点、长长地、整根、到最深 → 幅度大；小一点、只动前端、只弄龟头、浅一点 → 幅度小。
- 更久、再坚持一会 是时长，不是频率。
- 不许射、不准出来、还不可以 是结果约束：不是停止，也不自动加速。可以射了、射出来吧 是结果许可：同句有加速表达才加速，否则 continue。
- 好了、可以了、再来：看上下文，可能是结束、恢复或评价。

## 玩法对照（场景推断参考，原文优先）
- 手交、打飞机辅助（撸管指导）：中速中幅，逐步指令最多，最适合直接映射。
- 寸止、吊胃口、边缘控制、射精管理：慢速小幅与暂停交替；等一下、还不行、忍住 → 暂停或减速；再来 → 恢复；常配合倒计时推进。
- 倒数、最后冲刺：数字递减是台本进度；临近 0 且伴随加速表达时才加速。
- 足交、素股、乳交、骑乘、抽插：中到大幅；节奏以台词拟声（啪啪、咕啾、滑溜溜）为线索，周期不凭字数猜。
- 口交、舔舐、侍奉：中速小到中幅；啾啵、舔舔 等拟声表示持续进行。
- 前戏、舔耳、耳语、乳头责、ASMR：多为低强度，慢速小幅或保持；只有声音触发而没有往返动作的，写 no_new_information。
- 前列腺开发、后庭：慢速小幅，随台词逐步加深或加快。
- 催眠、呼吸引导：吸气、呼气可对应慢速大幅的呼吸节奏，仅当台词要求随之动作。
- 淫语、言语挑逗、赞美描写：多为描写；场景内运动进行时记 maintain 或 continue，不当作新指令。
- 一起、配合我、跟着声音：保存跟随意图（rhythm_follow），周期需音频证据。
- 事后、余韵、温存、晚安：结束，不重新启动。

## 情境关系
- 数字与口令：倒计时是台本进度（control=countdown）；“做几次”是定次重复（repetition，单程或往返不明则 unknown）；拟声词、“跟着声音”是节奏跟随（rhythm_follow，无音频锚点不编造周期）。不自动把倒计时换成逐档加速。
- 暂停中的描写不自动恢复；恢复沿用已确认参数；局部循环、轮次切换、重复强调不重置参数。
- 情绪、催促、责备用于理解意图；语气强烈不等于更快或更大。
- 规则讲解、口令定义、未来邀约不提前执行；活动结束后的回顾与评价不重新启动。
- 规则、阶段、持续关系记入 context_notes；需要执行的变化另记 events；每项引用原文。
