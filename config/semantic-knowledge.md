# 语义与运动意图参考（中文字幕及日文原语言转写）

本文件是可编辑的解释参考，不是本素材事实、固定流程或参数表。允许结合场景理解隐含意图；原文优先，推断说明依据。模型判断意图，数值与默认参数由融合配置提供。

## 判断顺序
- 确认对象：主动运动、准备、情绪、身体状态还是结果过程。准备和结果过程不能直接映射为周期动作。
- 确认时间：当前执行、规则定义、条件触发、未来安排、引用或事后评价。规则说明不提前执行。
- 有新增控制才输出事件；背景可仅有笔记或no_new_information，不强迫每句输出maintain。
- 判断否定对象：“别动”和“别停”不同。描述或问句可能含请求，保留真实句型与不确定性。

## 跨句与转写
- 规则、阶段和任务跨句继承，引用实际来源。暂停中的背景描述不自动恢复；结束后的回顾不重新启动。
- 倒计时、时长和规定次数不同。重开需reset；范围或单位不明保留未知，不把所有数字都当次数。
- ASR可能错漏、重复或断句错误。一段多句不表示意图同时生效；不由段落长度或文字重复猜时间、次数或节拍。
- evidence和quote复制输入原文，包括日文与实际识别错误；中文只用于解释。不能把译文当作原文证据。
