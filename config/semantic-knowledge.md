# 运动意图参考

目标：从台词与前后文提取可映射到手部往返运动的控制意图。先判断说话者要求什么、作用于什么，再判断活动应开始、延续、暂停、恢复，还是改变频率或幅度。不要把叙述中的所有事情都转换成运动。

没有规则说明也可结合语境推断；明示、继承与推断须区分。能确定开始或恢复，但缺少参数时，保留意图、参数填 unknown，交给配置补全。

常见表达：
- 开始、动起来：开始；准备、未来安排与规则讲解不提前执行。
- 继续、接着：活动中延续，暂停后恢复；保持、照这样只维持现状。
- 等着、先别动、停一下：结合上下文判断暂停；引用或定义口令时不执行。
- 别停、不能停：否定停止，要求继续。
- 快一点、慢一点：相对频率变化，不自行补绝对档位。
- 更久、再坚持一会：持续时长变化，不等于频率变化。
- 大一点、小一点：确认修饰对象确为动作幅度，不能混同音量、情绪或结果。
- 跟着声音、按节拍：保存跟随意图；具体周期需音频证据。
- 好了、可以了、再来：可能是开始、恢复、结束或评价，必须结合前后文。

情境关系：
- 数字或口令可能是进度、触发或普通叙述；有规则则关联规则，无规则则说明推断依据。不自动把倒计时换算为逐档加速。
- 分清数字的用途：倒计时表示台本进度；“做几次”限定重复次数；拟声词可能提示节奏跟随。次数须区分单程与完整往返，不明确就标 unknown，不按文字重复数猜节拍。
- 这三类控制写入 context_notes.control。进度不代表测得的生理状态，不预设加速曲线；声音同步需实际音频锚点，完成次数需执行结果确认。
- 暂停期间的描述不自动恢复；恢复沿用已确认参数。局部循环、轮次切换和重复强调不自动重置参数。
- 情绪、催促、责备与结果约束用于解释意图。先确定它们针对动作、执行结果还是状态评价；只有有据的运动要求才改变参数。
- 结果尚未获准不等于动作必须停止；语气强烈不等于速度更快或幅度更大。
- 当前活动结束后，回顾、评价和未来邀约不重新启动。

规则、阶段、持续关系与候选情境记入 context_notes；需要执行的变化另记 events。每项引用原文，不机械匹配关键词，也不强套固定情境。
