# 原语言转写与语义校验

Whisper输入使用 `src/funscripter/prompts/whisper.txt`，导入字幕使用 `subtitles.txt`。两者均将原语言证据与中文解释分开，不预设输入是中文字幕。`config/semantic-knowledge.md` 提供可编辑的中日表达线索，仍是提示词参考，不是训练模型或见词触发动作的规则。

## 判断与证据

原文引用不翻译、不纠错，不从译文反推证据。准备与正式开始、身体状态与主动运动、结果过程与运动速度分别判断。日文否定、条件、委婉请求和省略需结合上下文；重复文字不能当成实际节拍或次数。一段多句无法表达准确顺序时保留不确定性，不把全部意图提前到分段起点。

无需每句都输出maintain。没有新增控制可只评估no_new_information，持续关系可以记录笔记。来源、控制起点与原文覆盖仍严格检查，错误反馈会指出相关cue和缺失引用。

## 程序补齐的范围

- 未知意图、不确定范围、非起点锚点、非直接指令或ambiguous评估要求复核。模型遗漏needs_review时程序补true；理由为空时使用明确注明“原模型未提供理由”的系统复核说明。
- processed评估没有对应事件或情境笔记时，标为ambiguous并保留原理由，注明模型未提供内容；不补造动作，也不将其当成已确定的no_new_information。
- 不自动改写动作意图、参数、句型、证据、来源和时间，不将描述改成指令。

原始回答保存在 `response-N.json`。补齐内容保存在 `normalizations-N.json` 及请求日志的normalizations字段；查看请求的“校验/耗时/用量”元数据可以看到program_validation。最终保存的结果仍须通过严格校验。

若某批仍有证据问题，先保留从首条开始的连续合格前缀，状态为accepted_partial，保存partial.json；下一次从错误条及其后续开始分析，维持时间顺序。不是任意丢弃错误条，也不声称只重试单条；不能提取有效前缀时沿用校验反馈重试及缩小批次。完整覆盖和来源检查仍生效。

## 生效与验证

提示词版本为 `two-pass-10-original-language-review-normalization`，提示词和知识内容参与运行签名。重启工作台后使用新的规划输出目录；已运行的任务继续使用其启动时加载的旧设置，不会中途切换。已有转写项目无需重新转写。
