# 跨批次语义上下文与证据

后续批次除局部上下文和规则笔记外，也提供保留下来的历史事件所引用的原始字幕。历史暂停、继续或任务事件即使离开局部窗口，仍可核对其原文，避免只有事件解释却找不到可引用来源。原始文字不翻译、不替换、不裁掉用语。

上下文不足时，移除可选历史事件也同步移除仅供它引用的额外上下文；局部上下文、持久规则及其他保留事件仍需引用的原文继续保留。请求中记录历史事件省略数量，已保存的分析结果不受影响。

情境笔记按目标字幕顺序稳定排序，同一句内部保留模型返回顺序，避免乱序回答使旧控制覆盖新控制；不推测同句内未表达清楚的时序。

这些检查保证引用可用和存储顺序，不代表模型已经正确理解台词，也不自动确认触发条件或生成新的运动参数。无需调整运动参数或删除现有参考文件。

`tests/test_semantic_context_sources.py` 覆盖跨批次来源、预算缩减、持久规则、笔记顺序和原文保留。测试使用模拟模型响应，尚未验收真实音声的模型识别准确率。
