# 本地桌面测试界面

在仓库根目录双击 `launch_gui.cmd`，或运行：

```powershell
python tools/gui.py
```

使用项目已有 Python 依赖和 Tkinter，不需要安装网页框架。Python 若缺少 Tkinter，需要在 Python 安装器中添加 Tcl/Tk 支持。安装项目后也可运行 `funscripter-gui`。默认结果目录为启动目录下的 `workspace/desktop`，可通过 `--workspace 路径` 更改。

1. 在“输入与项目”选择音频或视频和 SRT/LRC/VTT；确认 FFmpeg、编码和字幕偏移。视频还需 FFprobe，可指定从 0 开始的音轨序号，再点击“创建新项目”。也可选择已有项目目录并校验打开，详见 [视频导入说明](video-inputs.md)。
2. 无模型时，可在“分步测试”直接运行“分析音频”。结果目录会自动填入，完整结果及问题在日志和对应文件中查看。
3. 启动本地 Ollama 或 llama.cpp 服务，在“本地模型”选择协议、填入实际地址及模型 ID，再测试连接。测试会发送一条简短 JSON 请求，不发送音频或字幕。
4. 连接成功后运行“模型规划”。它读取字幕，使用界面当前配置生成独立模型 YAML 快照；规划仍有两遍业务校验，连接成功不代表真实素材规划成功。
5. 可运行“句尾候选”；选择融合配置，运行“融合草稿”。再确认诊断 YAML 内 FFmpeg、FFprobe、字体路径，运行“诊断视频”。示例融合预设是离线演示参数，需按目标用途配置和复核。

Ollama 示例地址为 `http://127.0.0.1:11434`，llama.cpp 示例地址为 `http://127.0.0.1:8080`。切换协议时需同时修改地址。界面不会安装服务、下载模型或自动选择模型。模型文件存放在哪里由本地模型服务管理。

模型 YAML 可保存、载入，未在表单展示的高级字段会保留。认证只填写环境变量名，密钥值通过启动界面的进程环境读取。例如先在 PowerShell 中设置 `$env:LOCAL_MODEL_KEY`，再从同一终端启动界面。

后台任务串行运行，窗口显示运行状态；当前版本没有取消按钮，运行中应等待任务结束。每步使用新的输出目录，不覆盖已有项目；任务 JSON 保存在结果目录旁的 `.funscripter-tasks`，失败详情和 CLI 恢复仍沿用 [任务管理](tasks.md)。重新打开界面后可手动选择之前的项目及各阶段结果目录，界面不自动恢复会话。

当前界面提供文件选择、配置和运行入口。视频与脚本仍在输出目录交由播放器、OFS 等工具查看；未包含内嵌波形编辑器、设备控制或硬件验收。
