# 来源台本的语义动作范例

本例根据 `workspace/desktop/20261110-plan-repaired/requests` 保存的原始字幕整理，是对已有台本的控制关系分析。它不是新台本，也不是已确认的全轨动作标注。

通用控制关系已精简到 `config/semantic-knowledge.md`，当前 Qwen 配置会在下一次完整规划时加载。具体字幕编号和逐句案例只保留在本文件与 JSON 中供人工阅读，不自动发送给模型；字幕 ID 不能作为匹配条件。

## 应还原的连续关系

说明阶段 → 建立控制规则 → 进入活动 → 按已知条件暂停 → 保持等待 → 恢复此前活动 → 持续与局部变化 → 结束。

这只是本素材中能从原文找到的关系。其他素材可能从中途开始、没有说明、临时改口或并行描述多个对象。模型应以实际原文修正自己的候选理解。

## 示例 JSON 怎么使用

`config/examples/script-intent-reference.json` 是按当前 SemanticBatchV2 结构保存的部分参考标注，包含原文片段证据。它展示规则笔记、跨句指代、继续、持续关系和相对加速等写法。

它不是完整 400 条字幕的规划，也不应直接作为原项目的融合输入。它的目标字幕是该文件 `cue_assessments` 列出的子集；来源证据还引用了必要的前后文。程序已对照保存原文验证 Schema、来源引文和目标覆盖。

知识文件中的范例供模型参考；JSON 不会自动注入提示词。需要调整模型行为时，优先修改 `config/semantic-knowledge.md` 中相应的解释和正反例。

## 如何判断还原效果

先检查开始、暂停、恢复和结束的状态是否与原文相符，再检查速度、幅度和节奏依据。动作多不代表正确；应暂停时暂停、应恢复时恢复、描述期间保持正确的连续状态，才是本例的主要验收目标。

对原文未给全的参数，生成器可以使用已配置的 action_defaults，但必须把它当作编辑偏好，不能宣称是人物原文明示。情境笔记也不会自动变成音频同步或新的运动样式。
