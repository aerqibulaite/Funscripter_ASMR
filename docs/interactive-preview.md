# 交互式脚本预览

无需合成视频、调用模型或连接设备。页面展示已保存融合修订的实际候选曲线，附带项目的分析音频；导出通常主要花在读取波形、校验文件及复制 WAV 上。复制的 WAV 与预览放在一起，可离线播放，长音轨需要相应磁盘空间。

## 使用

重启桌面程序，在“分步测试”选择项目、融合草稿，点击“生成交互预览”，完成后点击“打开交互预览”。可选择已有交互预览目录直接打开。填写与该融合修订匹配的模型规划目录，可显示原始事件解释和证据；省略时仍展示台词、状态及融合依据。

也可运行：

```powershell
python tools/run.py preview PROJECT --draft FUSED_DRAFT --planning MATCHING_PLAN --output NEW_PREVIEW
```

`--planning` 可省略。输出目录必须不存在，并且在源项目、融合与规划目录之外。双击结果目录的 `index.html` 即可查看，保留旁边的 `viewer.js`、`viewer.css` 和 `audio.wav`。不需要启动网页服务，页面没有外部依赖或网络请求。浏览器需支持本地 PCM WAV 播放。

## 浏览方式

- 整轨曲线：点击任意位置定位，橙色短线标记问题起点。
- 局部视图：10/30/60 秒或整轨显示，联动音频包络、位置和速度。拖动浏览位置可关闭跟随播放；重新勾选可继续跟随。
- 试听：音频控件、前后移动 5 秒、A/B 循环。非输入控件焦点下，空格播放或暂停、左右键移动。
- 台词与依据：显示当前区间状态、预设、融合理由、附近台词和相关事件，点击台词时间可跳转；重叠字幕同时展示。
- 快速检查：搜索台词，跳到上一处/下一处问题，检查未解析、冲突、含糊语义和连续静止至少 10 秒的区间。

整轨统计来自脚本点之间的线性插值：运动时长是位置不同的相邻点之间的时间总和，静止区间会跨同位置边界点合并，速度是位置差绝对值除以时间差。方向变化数忽略零位移段。有限任务完成后的保持按真实曲线计为静止，而不是按预设段长度计为运动。静止与未解析标记用于筛查，不代表必须有运动。

音频包络为整轨 4096 桶，放大时不会重新提取高精度波形；曲线保留全部脚本点。总览密集时按像素聚合极值，局部查看可见具体变化。

## 来源与限制

创建预览前校验项目和融合产物哈希；规划目录还需与融合记录中的规划清单哈希一致。未通过设备约束的融合结果也可查看，页面明确标注“约束失败 · 候选曲线”。查看不等于导出许可，也不代表设备已执行。

动画只按单轴位置做线性插值示意，不模拟多轴机构和设备动力学。原始插值配置可能仍未确认，外部播放器的实际插值效果需另行核对。页面不修改脚本或复核记录。

导出器、来源校验、统计、文本转义及播放/定位/缩放/循环逻辑使用自动测试验证。浏览器界面仍需在目标电脑上检查，真实素材的语义和听感不由这些测试确认。
