日期：2026-11-09

已实现严格 YAML 配置及 JSON Schema、LRC 导入、毫秒时间映射、PCM 分析副本、手工段落与预设生成、最终曲线约束检查、项目事务式创建与恢复、CLI 和合成样本。

本机 PATH 无 FFmpeg，已使用显式 PCM WAV fallback 验证。模型、网络服务和硬件不参与 M1。

剩余验收：

1. 有 FFmpeg 的环境下验证 WAV/FLAC/MP3 解码、编码延迟及首中尾同步。
2. OFS 实际载入媒体和脚本，检查跳转、暂停、插值、另存及重开；纯音频支持不足时在 M4 加入诊断视频。
3. MultiFunPlayer 实际验证媒体源、主轴匹配、偏移、暂停、跳转与同步。
4. 真实 LRC 验证双语、空时间戳制作约定和偏移；合成素材不证明真实生成质量。

当前状态：M1 代码骨架完成，外部兼容性待验证。低成本句尾只保留空时间戳候选，VAD、分频特征与候选自动采用留待 M2/M3。辅助分轨接入后需补同步核验，不是首个主轨闭环依赖。
